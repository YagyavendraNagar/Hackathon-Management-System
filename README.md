# 🚀 Hackathon Management System

## 📌 About the Project

The **Hackathon Management System** is a database-driven project designed to simplify and manage hackathon-related activities. It aims to provide an organized way to handle hackathon information, participants, teams, and other event-related operations.

This project is developed as part of an academic project.

## 🎯 Objectives

- To simplify hackathon management.
- To maintain organized database records.
- To manage hackathon-related information efficiently.
- To reduce manual work and improve data management.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Database:** MySQL
- **Database Management Tool:** MySQL Workbench
- **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/YagyavendraNagar/Hackathon-Management-System.git
```

2. Open the project folder:

```bash
cd Hackathon-Management-System
```

3. Import the SQL file into MySQL Workbench.

4. Configure the database connection in `backend/database.py`.

5. Install the required Python dependencies according to the project requirements.

6. Run the backend using the appropriate Python command.
